This class require you to do **a lot** of coding using Advance C concepts.
This also requires you do debug complicated C code involving pointers.

We provide some exercises for you to self-guage your expertise.

* [Pointer Manipulation](https://github.com/EE469/c-knowledge-test/blob/main/pointer_manipulation.md)
* [Integer Overflow](https://github.com/EE469/c-knowledge-test/blob/main/integer_overflow.md)
* [Buffer Overflow](https://github.com/EE469/c-knowledge-test/blob/main/buffer_overflow.md)

If you have __severe difficulty__ in understanding/solving the above exercises, **we strongly recommend you to re-consider taking this course 
or brush up fundamentals of pointers in C (You can find a few materials under "Reference Materials").**
